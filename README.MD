📌 Purpose
This repository is designed to help you practice and gain hands-on experience with essential Dockerfile instructions. It serves as a learning resource for understanding how Dockerfiles are written and used in real-world development environments.

🧱 Dockerfile Instructions Covered

This repository includes examples and explanations for the following Dockerfile instructions:

🔹 FROM

Defines the base image for building your container.

🔹 RUN

Executes commands during the image build process.

🔹 COPY

Copies files or directories from the host into the container.

🔹 ADD

Similar to COPY, but also supports remote URLs and automatic extraction of archives.

🔹 WORKDIR

Sets the working directory inside the container.

🔹 USER

Specifies the user to run commands as inside the container.

🔹 ENV

Sets environment variables.

🔹 ARG

Defines build-time variables.

🔹 LABEL

Adds metadata to the image (e.g., author, version).

🔹 EXPOSE

Documents the port the container listens on.

🔹 CMD

Specifies the default command to run when a container starts.

🔹 ENTRYPOINT

Configures a container to run as an executable.

🔹 ONBUILD

Adds triggers that execute when the image is used as a base for another build.
